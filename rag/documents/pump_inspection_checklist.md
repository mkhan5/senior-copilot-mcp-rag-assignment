## Pre-Inspection Safety
- [ ] LOTO verified if maintenance performed

- [ ] Area clear of hazards
- [ ] Communication with control room established

## Visual Inspection

### Pump Casing
- [ ] No visible leaks (mechanical seal, gaskets, flanges)
- [ ] No corrosion or erosion visible
- [ ] Casing bolts tight
- [ ] Insulation intact (if applicable)
- [ ] Drains/vents clear

### Piping
- [ ] Suction piping - no leaks, supports intact
- [ ] Discharge piping - no leaks, supports intact
- [ ] Valves - correct position, no leaks
- [ ] Pressure gauges readable

### Motor
- [ ] No abnormal noise
- [ ] No visible oil/grease leaks
- [ ] Coupling guard secure
- [ ] Motor cooling fan operating
- [ ] Terminal box sealed

### Base/Foundation
- [ ] No cracks in grout
- [ ] Anchor bolts tight
- [ ] No excessive vibration visible
- [ ] Level within tolerance
